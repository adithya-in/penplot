Settings

Invert Y is on by default — this plotter's Y motor is mounted in reverse. Tick another axis only if it moves the wrong way, then press Apply. X flips left/right, Y flips up/down, Z reverses pen up/down.

Quick start

      

        
    
          
  1. Flash the Nano. Run flash.ps1 in the project folder (or double-click flash.bat). Choose the COM port when asked. The firmware is the GRBL 28BYJ-48 fork already configured for this plotter.
    2. 
          
  2. Wire the drivers. X coils → D2–D5, Y coils → A0–A3, Z coils → D8, D9, D12, D13. Power the three ULN2003 boards from a separate 5 V ≥ 2 A supply; join its ground to the Nano ground. Never power the motors from the Nano.
    3. 
          
  3. Connect & zero. Tick “Always allow” when Chrome asks for the serial port. Jog the pen to the bottom-left corner of the paper and press Zero here.
    4. 
          
  4. Calibrate. Use the calibration wizard: command 10 mm, measure the real move, and enter it. Then set pen down/up heights.
    5. 
          
  5. Draw. Pick an image/SVG/text, press Draw. Start with something small — 28BYJ-48 motors are slow.
    6. 
        

        

          Before the first run: test with the pen lifted and your hand on the power switch. The stock machine has no limit switches, so the app clamps paths to the paper size instead.
        

        

          GRBL settings can be changed live from the Settings card. Apply writes them to EEPROM. $$ in the console shows the current values.
